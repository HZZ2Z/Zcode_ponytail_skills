# Ponytail — Lazy Senior Dev (ZCode 插件)

防过度工程化的懒人高级开发模式,移植自 [DietrichGebert/ponytail](https://github.com/DietrichGebert/ponytail)(MIT)。

## 安装

1. 打开 ZCode:**Settings → Plugin Management → Discover**
2. 点 **`+`** 添加 marketplace,输入本仓库:`HZZ2Z/Zcode_ponytail_skills`
3. 在 **Ponytail** 卡片上点 **Get**,装完默认启用
